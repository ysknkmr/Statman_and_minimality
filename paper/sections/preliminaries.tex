\section{Preliminaries}\label{sec:prelim}

\subsection{Formulas and logics}

Except in Section~\ref{sec:fl}, we work in the implicational language:
formulas are built from variables by the implication $\to$. As usual,
implication associates to the right: $\alpha\to\beta\to\gamma$ stands for
$\alpha\to(\beta\to\gamma)$. \AP The \intro{order} $\intro*\Ord(\alpha)$ of
a formula $\alpha$ is defined by $\Ord(p)=1$ for variables $p$ and
$\Ord(\alpha\to\beta)=\max\{\Ord(\alpha)+1,\Ord(\beta)\}$, and its
\intro{height} by $\intro*\hgt(p)=0$ and
$\hgt(\alpha\to\beta)=1+\max\{\hgt(\alpha),\hgt(\beta)\}$.

A \emph{substitution} $\sigma$ is a map from variables to formulas, and
$\sigma\alpha$ denotes the result of applying $\sigma$ to $\alpha$.
\AP A \intro{logic} is a set of formulas
that is closed under modus ponens and substitution. For a set $F$ of
formulas, $\intro*\lclos{F}$ denotes the smallest \kl{logic} containing
$F$, and for a \kl{logic} $L$ we write $L\intro*\lplus F$ for
$\lclos{(L\cup F)}$ and $L\lplus\alpha$ for $L\lplus\{\alpha\}$. We shall
repeatedly use the following closure properties of a \kl{logic} $L$:
\begin{enumerate}
\item[(C1)] if $\gamma\in L$, then $\sigma\gamma\in L$ for every
  substitution $\sigma$;
\item[(C2)] if $\gamma_1\to\dots\to\gamma_k\to\beta\in L$ and
  $\gamma_1,\dots,\gamma_k\in L$, then $\beta\in L$;
\item[(C3)] $\gamma\to\gamma\in L$ for every formula $\gamma$.
\end{enumerate}
Every \kl{logic} satisfies (C1) and (C2), and by (C1) a \kl{logic}
satisfies (C3) if and only if it contains the identity axiom
$\intro*\axI=a\to a$.

\subsection{The substitution preorder}

\AP We write $\beta\intro*\sub\alpha$ if $\alpha=\sigma\beta$ for some
substitution $\sigma$, and $\beta\intro*\ssub\alpha$ if $\beta\sub\alpha$
but not $\alpha\sub\beta$. The relation $\sub$ is the
\intro{substitution preorder}. If $\beta\ssub\alpha$, we say that $\beta$
is \intro{strictly more general} than $\alpha$.

\begin{definition}
\AP A formula $\alpha$ is \intro{minimal in} a \kl{logic} $L$ if
$\alpha\in L$ and there is no $\beta\in L$ with $\beta\ssub\alpha$.
\end{definition}

\subsection{Occurrences and a criterion for minimality}

\AP We identify an occurrence of a subformula in a formula $\alpha$ with its
position in the syntax tree of $\alpha$, that is, with a finite word over
$\{0,1\}$. The empty word $\intro*\rt$ denotes the root, and if
the subformula at $u$ is $\gamma\to\delta$, then $\gamma$ is at $u0$ and
$\delta$ is at $u1$. We write $\intro*\subf{\alpha}{u}$ for the subformula
of $\alpha$ at $u$. An occurrence $u$ is \intro{strictly below} $v$ if $v$
is a proper prefix of $u$. An occurrence $u$ is a \intro{leaf} if
$\subf{\alpha}{u}$ is a variable, and a \intro{non-leaf occurrence}
otherwise. Note that two distinct occurrences of the same formula are never
\kl{strictly below} one another.

\AP Let $Q$ be a set of occurrences in $\alpha$ such that no element of
$Q$ is \kl{strictly below} another, and let $z$ be a variable. We write
$\intro*\gen{\alpha}{Q}{z}$
for the formula obtained from $\alpha$ by replacing the subformula at each
$u\in Q$ by $z$.

\AP We write $\intro*\Gen{\alpha}$ for the set of formulas
$\gen{\alpha}{Q}{z}$ such that $Q$ is a nonempty set of occurrences of a single
formula $\delta$ in $\alpha$, the variable $z$ does not occur in $\alpha$,
and, if $\delta$ is a variable, some occurrence of $\delta$ does not belong
to $Q$ (replacing all occurrences of a variable merely renames it).

\begin{proposition}\label{cor:criterion}
Let $L$ be a \kl{logic} and let $\alpha\in L$. Then $\alpha$ is \kl{minimal} in $L$
if and only if $\Gen{\alpha}\cap L=\emptyset$.
\end{proposition}

This is essentially \cite[Props.~3.1 and~3.2]{NM21}; for completeness, we
give a proof in Appendix~\ref{app:criterion}.
